# OpenManul编辑说明

OpenManul是一个开放动物园展览动物数据集，旨在呈现动物个体的饲养情况及其个体之间的亲缘关系，并尽可能地保证数据的可备份、可恢复性。任何人可以在任何时间备份任何一个版本的OpenManul数据，以便在网络访问存在困难或者运营商停止存储服务时通过自己的备份数据还原出数据全貌。任何人可以通过git创建数据库分支，并在自己的分支上修改这个数据集，也可以通过提交pull request将自己对数据集的修改申请合并到这里。

本数据集由yaml文件以特定目录结构组织而成，yaml文件内部的结构遵循ID+信息的结构，动物个体、动物园、生产信息、图片资源都通过唯一的ID进行关联，ID的格式、yaml文件的格式和其他修改注意事项见此说明书的具体章节。

本数据集的数据结构服务于网站的呈现，主分支数据集的数据呈现在[这个网址](manul.apiglio.top)；这个网站由专门的[openManulServer项目](https://github.com/Archmanoelogy/openManulServer)实现，可以在任何常见PC设备上通过安装python3实现和网站相同的本地部署。该项目同时可以判断数据集修改后是否完整有效，如果您希望将自己修改的版本合并到这里，十分建议按照此项目的指引在本地测试，保证提交的数据的结构完整性。
